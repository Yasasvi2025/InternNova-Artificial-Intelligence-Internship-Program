# Rule-Based AI Chatbot Using Python

## Project Description
This project is a simple Rule-Based AI Chatbot developed using Python. It interacts with users and provides predefined responses based on their input.

## Objective
To understand basic AI chatbot functionality using Python conditional statements without Machine Learning.

## Technologies Used
- Python 3
- VS Code

## Features
- Responds to greetings.
- Answers simple questions.
- Recognizes user messages.
- Provides predefined responses.
- Exits when the user types bye.

## Python Concepts Used
- Input and Output
- If-Elif-Else statements
- While Loop
- Break Statement
- String Functions (`lower()` and `strip()`)

## How to Run the Project
1. Install Python 3.
2. Open the project in VS Code.
3. Create a file named `chatbot.py`.
4. Copy the Python chatbot code into the file.
5. Open the terminal.
6. Run the following command:
   ```bash
   python chatbot.py
   ```

## Sample Interaction
```text
You: hello
Bot: Hello! Welcome.

You: how are you
Bot: I'm fine. Thank you!

You: bye
Bot: Goodbye! Have a nice day!
```

## Conclusion
This project demonstrates a basic Rule-Based AI Chatbot using Python. It helps beginners understand how chatbots work using conditional statements and loops.
